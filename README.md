# Planto 🌱

Planto helps you keep track of when your plants need water. Set care reminders, record watering, and see which plants need attention today.

## Main features

- Add, edit, and delete plants with their room, light level, watering interval, and water amount.
- View today's reminders and upcoming watering dates.
- Mark due plants as watered and undo today's completion.
- Track daily progress and see an All Done screen.
- Keep plants and watering history saved on the device.
- Enable local watering notifications with your permission.

## Technologies

Swift, SwiftUI, MVVM, Combine, local JSON storage, and UserNotifications. The app uses a dark appearance and Liquid Glass controls on iOS 26+.

## Run

Open `Planto.xcodeproj` in Xcode 26+, select the **Planto** scheme and an iPhone simulator, then press **⌘R**. The app runs on iOS 17 or later.
